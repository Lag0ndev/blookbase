# Blookbase

Fanmade Blooket hub — countdowns, Season 8 leaks, videos, and live streams.

**Not affiliated with Blooket.**

## Deploy

Import this repo on [Vercel](https://vercel.com). `vercel.json` rewrites routes to `index.html`.

## Pages

- `/` — Home
- `/countdown` — Seasonal countdowns
- `/whatsnew` — What's New
- `/leaks` — Secret / unreleased Blooks & gamemode leaks
- `/tracker` — Live CDN tracker + update feed
- `/videos` — Blooket videos
- `/gamemodes` — Gamemodes
- `/about` — About
