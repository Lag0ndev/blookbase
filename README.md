# Blookbase

Fanmade Blooket hub — countdowns, Season 8 leaks, videos, and live streams.

**Not affiliated with Blooket.**

## Deploy

Import this repo on [Vercel](https://vercel.com). `vercel.json` rewrites all routes to `index.html` so paths like `/countdown`, `/leaks`, `/videos`, `/live`, and `/about` work.

## Pages

- `/` — Home
- `/countdown` — Seasonal countdowns
- `/leaks` — Season 8 leaks
- `/videos` — New & Popular Blooket videos
- `/live` — Livestreams / VODs
- `/about` — About
